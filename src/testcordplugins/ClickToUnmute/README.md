# Click to unmute

DavidHiFi's maintained fork of [Kurtzon Audio's ClickToUnmute](https://github.com/kurtzonaudio/kurtcord-plugins). Click a locally muted voice member's mute icon to unmute them. The patch captures the row's user instead of relying on fixed minified variable names.

Original author: [Kurtzon Audio](https://discord.com/users/1552878708732469258). Maintainer: DavidHiFi. Both remain in the plugin author list. TestCord source uses the required GPL-3.0-or-later Vencord header; the original MIT grant remains in LICENSE.

Enable ClickToUnmute in TestCord plugin settings. Rebuild and reload TestCord after source changes to activate the patch.
